# 面试八股 · 记忆卡

一个本地运行的面试记忆卡网站，交互类似 Anki：先看题，自己决定什么时候翻答案，再自评记得怎么样，系统按遗忘曲线安排下次复习。不依赖任何外部资源，可以离线使用。

| 牌组 | 卡片 | 英文解析 |
| --- | --- | --- |
| SDE 面试八股 (Python) | 144 | 全部有 |
| RAG 面试八股 (LlamaIndex) | 78 | 全部有 |
| 面试八股文 | 3329 | 暂无 |

## 启动

需要 Python 3，不用安装其他东西。

```sh
cd "/Users/kejunliu/quick access/Job/Interview_Anki"
python3 -m http.server 8538 --bind 127.0.0.1
```

然后在 **Chrome** 打开 <http://127.0.0.1:8538/>。用完在终端按 Ctrl+C 停止。

## 怎么学

1. 在「学习」页勾选牌组，点「开始学习」。第一次打开默认只勾选 SDE 和 RAG 两组。
2. 看到题目后先想一想，按空格翻面。
3. 按实际情况评分。按钮上会显示这张卡下次出现的时间。

| 按键 | 作用 |
| --- | --- |
| `空格` / `回车` | 翻面；翻面后等于选「记得」 |
| `1` `2` `3` `4` | 忘了 / 困难 / 记得 / 轻松 |
| `L` | 切换解析语言：双语 / 中文 / 英文 |
| `Z` | 撤销上一张 |
| `S` | 标星 |
| `N` | 写笔记（翻面后） |
| `B` | 今天跳过，明天再出现 |
| `X` | 不再复习，可在「浏览」页恢复 |
| `Esc` | 回到牌组 |

## 复习是怎么安排的

每张学过的卡有一个「稳定度」S：记忆保留率降到 90% 所需的天数。保留率按指数遗忘曲线估算：

```
R(t) = 0.9 ^ (t / S)
```

保留率降到目标值时，这张卡就到期了。如果每次都选「记得」，间隔大约是：

```
10 分钟 → 1 天 → 3 天 → 6 天 → 16 天 → 1.3 个月 → 3.3 个月 → 8.1 个月
```

安排不会很死板：

- **没做完没关系。** 积压的卡按保留率从低到高出现，先复习快忘掉的，不会因为隔了几天就被清零。
- **晚复习有奖励。** 隔了很久还记得，说明记得比估计的牢，间隔会涨得更多。
- **早复习不吃亏。** 按实际隔了多久折算增长，复习多少都不会让间隔变短。
- **忘了不清零。** 选「忘了」会在 10 分钟后重学，稳定度保留 30%。
- **上限可以突破。** 学完后可以「再来 10 张新卡」「继续复习顺延的卡」或「提前复习 20 张」。
- **学习步骤不用干等。** 没有别的卡时，短间隔的卡会直接提前出现。
- **强度可调。** 「设置」里可选轻松（80%）、标准（90%）、冲刺（95%），改完立即对所有卡生效，面试前可以切到冲刺。
- **随便看不影响进度。** 「浏览」页可以搜索和查看任意卡片，不改变复习安排。

一个学习日到凌晨 4 点结束，所以熬夜复习仍算当天。算法在 [srs.js](srs.js)，不依赖页面，可以单独测试。

## 进度保存在哪

进度、标星和笔记存在浏览器的本地存储里，按浏览器和地址分开保存：

- 始终用同一个地址 `http://127.0.0.1:8538/`。换成 `localhost`、换端口或直接双击 `index.html`，都会看到空的进度。
- 始终用同一个 Chrome 用户。VS Code 内置浏览器的存储是分开的。
- 可以同时开多个标签页，它们会自动同步。

**记得定期备份。** 到「设置」点「导出进度」，会得到一个 JSON 文件，用「导入进度」恢复。备份不包含笔记里粘贴的图片，那些图片只存在当前浏览器的 IndexedDB 里。

## 更新卡片

卡片来自根目录的 `.apkg` 文件，`cards.js` 是生成的，不要手改。替换或新增 `.apkg` 后运行：

```sh
python3 build_cards.py
```

转换时会：

- 去掉原站的模板文字，把「原文」链接移到答案下方。
- 合并不同牌组里内容完全相同的题（14 张同一条笔记、145 张相同内容），合并后的卡在每个牌组都能看到。
- 移除原站没有人回答的空卡（141 张）。
- 把牌组里没有转义的代码（比如 `<mapper>`、`<stdio.h>`）显示成文字。

学习进度按卡片 ID 保存，ID 来自 Anki 的 guid，所以重新生成不会丢进度。

已知缺口：`面试八股文.apkg` 没有打包图片，243 张卡的图片缺失，页面上显示占位提示，可以点「查看原文」看原图。

## 添加英文解析

英文放在 [translations/](translations/) 下的 `.txt` 文件里，运行 `build_cards.py` 时会合并进去。没有英文的卡只显示中文。格式如下，答案可以写多行 HTML：

```
@@ <卡片 id>
Q: English question
A:
<b>English</b> answer
```

卡片 id 可以在 `cards.js` 里查到。id 写错时脚本会报错退出。
