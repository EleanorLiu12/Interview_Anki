Q: [Resume deep dive] LLM Decoding Visualizer: how did you implement top-p, and what are the edge cases?
A:
<pre><code>import torch
def sample(logits, T=1.0, k=0, p=1.0):
    if T == 0: return logits.argmax()
    logits = logits / T
    if k &gt; 0:
        kth = torch.topk(logits, k).values[-1]
        logits[logits &lt; kth] = -float('inf')
    probs = torch.softmax(logits, -1)
    if p &lt; 1.0:
        sp, idx = probs.sort(descending=True)
        cum = sp.cumsum(-1)
        mask = cum - sp &gt; p        # guarantees at least one token is kept
        sp[mask] = 0
        probs = torch.zeros_like(probs).scatter(0, idx, sp)
        probs /= probs.sum()
    cdf = probs.cumsum(-1)        # inverse-CDF
    u = torch.rand(1)
    return torch.searchsorted(cdf, u)</code></pre>
Edge cases: T=0, k larger than the vocabulary, keeping at least 1 token, numerical stability (subtract the max before softmax), and floating-point error leaving the end of the CDF &lt; 1.
